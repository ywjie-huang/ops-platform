📍 本版改动点（对比现版）

  • 1页头精简：去掉「已配置 / 未配置」全局标签；「未保存」从灰色升级为警示色，一眼可见
  • 2列表升级：meta 行显示模型名；「使用中」从 8px 小圆点升级为文字徽章；每个配置独立的未保存黄点；hover 出现 ⋯ 快捷菜单（复制 / 删除）；配置超过 6 个时显示搜索框
  • 3服务商选中后折叠为一行摘要，不再占 2～3 屏；点「更换」展开，按 国际 / 国内 / 本地 分组；瓷砖为大图标纵向卡片，字母占位换成真实品牌 Logo（本地 SVG 文件，frontend/src/assets/provider-logos/）——点击瓷砖试试，选中即自动折叠并同步到摘要行
  • 4「接口模式 / 推理强度」从服务商卡片移入连接配置，语义归位；非 Responses 模式时推理强度置灰
  • 5「测试连接」从页头移到连接卡底部，结果就地展示（含延迟与模型名），成功可一键关闭；与底部「快速测试」分工明确：一个验连通，一个验效果
  • 6快速测试默认折叠成一行，不挤压表单；宽屏（≥1440px）升级为常驻第三栏，边调参数边试聊（切到「宽屏三栏」查看）
  • 7新增粘性操作底栏：删除 / 复制 / 当前使用 / 保存集中一处，滚动时始终可达——保存按钮不再只挂在页头
  • 8修复 Max Tokens 滑杆（32768）与数字输入（128000）上限不一致的问题，统一为 32768
  • 另：状态色全部收敛到 CSS 变量（消除 #16a34a / #22c55e 双轨）；「复制」入口从 3 处收敛为 2 处（列表 ⋯ 菜单 + 底栏）。细节美化：滑杆随值填充、卡片错落入场、悬浮抬升、保存 Toast 反馈、编辑/保存的脏状态联动（改任意项 → 三处脏标记出现，保存后消除）、模型下拉可筛选、Ctrl+S 快捷保存。
