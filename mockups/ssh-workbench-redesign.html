1信息分层：身份与操作分离

顶部栏只放主机身份（头像、名称、地址、连接状态徽标）与全局操作（设置 / 全屏 / 断开）；会话专属工具（分屏、字号、文件面板）下移到标签行右侧，不再全挤在一行。

2标签栏独立成行

会话标签从 36px 工具栏的夹缝中解放，独立 42px 行高，浏览器式圆角标签 + 状态点 + 分屏标记，双击重命名、快捷键徽标保留。

3终端卡片化 + 窗格头

终端包一层圆角卡片，带窗格头（状态点、标题、当前路径、复制/清屏快捷钮）；聚焦窗格有蓝色描边光晕，分屏时一目了然谁是活动窗格。

4右侧面板收敛为 3 个真实功能

砍掉 Editor / Actions 两个占位的 placeholder，只保留「文件 / 命令收藏 / 会话信息」，页签改为分段控件样式；文件列表加图标、面包屑导航和行内操作。

5登录卡片重设计

未连接态从塞在终端里的表单改为居中卡片：认证方式改为可视化的密钥选择器，上次失败原因直接展示，主操作按钮突出。

6状态栏降噪

分隔点改为分段分隔线，信息分组：连接状态 / 终端尺寸 / 路径 / 凭据 / 布局；快捷键提示统一放右侧并用 kbd 样式弱化。
