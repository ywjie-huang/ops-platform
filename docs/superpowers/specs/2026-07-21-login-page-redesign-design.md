# 登录页重设计（V6 聚光点阵 + 拓扑面板）

## 背景

登录页历经多轮探索：暗绿指挥中心拓扑版（已上线于 `LoginView.vue`）、浅色 Linear 风原型、明暗融合版、星轨版（V3）、GitHub 极简版（V4）、聚光点阵居中版（V5）。逐轮评审后收敛出最终方向 **V6**：保留 V5 验证过的聚光点阵场景与居中玻璃登录卡，恢复左侧品牌面板并回归拓扑图，全部统一进同一套深色 teal 视觉体系。

参考原型：`docs/prototypes/login-v6-split.html`（最终稿）、`login-v5-spotlight.html`（居中无左栏变体）。

## 目标

- 登录页第一眼即传达"运维平台"身份，但不依赖堆砌功能截图或装饰元素
- 三层视觉职责分离：背景场景负责氛围、左侧面板负责品牌与酷感、右侧卡片专注登录任务
- 打开页面有"仪式感"（逐级入场 + 终端打字机），日常高频使用不疲劳
- 设计与前端栈（Vue 3 + Element Plus）可落地，动效全部 CSS 实现，无额外依赖

## 非目标

- 不展示实时数据（拓扑为示意接入关系，面板头部明确标注）
- 不做注册、找回密码、第三方登录（内部平台，账号由管理员开通）
- 不引入 JS 动效库（particles.js、TypeIt 等），打字机与流星均 CSS 实现
- 登录后的工作台视觉不在本文档范围

## 参考来源

| 参考 | 借鉴点 |
|------|--------|
| vue-pure-admin（GitHub 20.4k★，同栈 Element Plus） | 逐级入场动效（Motion 延迟队列）、登录仪式感 |
| Aceternity / Magic UI 系组件 | 点阵网格径向渐隐、顶部聚光束、流星动效 |
| GitHub / Vercel 登录页 | 表单工艺：发丝边框、克制的焦点态、单一高饱和主按钮 |

## 设计方向

- 基调：深色工程感（near-black `#04070d`，非纯黑、非墨绿）
- 色彩策略：单主色 teal→cyan 渐变，语义色（琥珀/蓝/紫）仅出现在拓扑中
- 动效原则：氛围动效在"远处"（背景层），任务区（卡片）保持静止稳定
- 字体策略：中文无衬线 + 等宽字体（mono）作为"工程信号"点缀（终端行、版本号、节点元信息）

### 拓扑面板

- 五节点：Ops Core（核心，teal 光晕）+ Prometheus / Alertmanager / K8s / Docker Agent
- 连线：四条贝塞尔虚线，青/琥珀/蓝/紫四色，不同流速（8~11s），虚线流动动画
- 节点：深色玻璃芯片（blur + 发丝边框），状态徽标呼吸点
- 面板头部：`运维拓扑` + `示意接入关系 · 非实时状态`

## 视觉规范

### 色彩

| 用途 | 值 |
|------|-----|
| 页面底色 | `#04070d` |
| 卡片底 | `linear-gradient(170deg, rgba(15,22,34,.82), rgba(9,13,21,.88))` + blur(16px) |
| 发丝边框 | `rgba(148,163,184,.14)` |
| 文本 | `#e8edf6` / `#97a1b3` / `#5f6b82` 三级 |
| 主色 | `#2dd4bf → #22d3ee` 渐变，文字高光 `#7ef0dd` |
| 语义色 | 琥珀 `#fbbf24`（告警）、蓝 `#60a5fa`（集群）、靛 `#818cf8`（容器/辉光） |
| 主按钮 | 渐变 `#5eead4 → #22d3ee`，深色文字 `#04211f` |

### 字级

- kicker / 底栏 / 节点 meta：mono 10.5~11px，字距 .08~.22em
- 页面标题：42px / 800，渐变文字（白 → teal → cyan）
- 卡片标签：13px / 600；输入框文字：14px
- 主按钮：14.5px / 800，字距 .06em

### 圆角与间距

- 卡片 / 拓扑面板：16px；输入框 / 按钮：10px；徽标 / 胶囊：999px
- 舞台：max-width 1180px，左右栏比例 1.08 : 0.92，间距 60px
- 登录卡宽 400px，内边距 26px，表单项间距 15px

## 动效规范

| 动效 | 参数 | 说明 |
|------|------|------|
| 逐级入场 | 6 级，delay .08s~.62s，上浮 16px，.65s cubic-bezier(.22,.8,.36,1) | 参考 vue-pure-admin Motion |
| 终端打字机 | 2.4s steps(31) 延迟 1s，光标 .9s 闪烁 | 文案 `$ opsctl login --env production`；宽度 32ch（含光标位），元素自身禁止 letter-spacing |
| 流星 | 4 颗，9~13s 错峰循环，rotate(215deg) 划过 | 仅背景层 |
| 拓扑流线 | dasharray 5 9，dashoffset 0→-140，8~11s 异速 | |
| 呼吸点 | 状态点 / 徽标点 2.4~2.6s opacity 脉动 | |
| 表单交互 | 边框 / 光晕过渡 140~160ms；按钮 hover 上浮 -1px + 亮度 1.07 | |

所有动效均为 CSS，无需 JS；实现时需补 `prefers-reduced-motion` 降级（关闭流星、打字机直接全显、关闭脉动）。

## 表单状态

- 默认 / hover（边框提亮）/ focus（teal 边框 + 3px 光晕 rgba(45,212,191,.14)）
- 错误：红色提示条（图标 + 文案），出现在验证码下方、按钮上方
- 验证码图：斜纹底 + 等宽字符 + 干扰线，点击刷新（原型为静态示意）
- 登录中（实现时）：按钮 loading 禁用，防重复提交；Enter 提交
- 失败（实现时）：错误条提示；连续失败锁定策略由后端安全控制决定

## 响应式

- ≤1020px：单栏堆叠，左侧面板在上，登录卡居中，拓扑面板 max-width 560px
- ≤560px：标题 31px，拓扑节点隐藏 meta 行，卡片内边距收窄，底栏精简

## 无障碍

- 拓扑 SVG 与装饰元素 `aria-hidden`，面板整体 `aria-label="运维拓扑示意"`
- 表单控件关联 label；焦点环对比度 ≥ 3:1；文本对比度 ≥ 4.5:1（深色底上 `#97a1b3` 以上）

## 验收标准

1. 首屏三级层次清晰：背景氛围不干扰、左侧品牌可读、右侧表单立即可用
2. 入场动画总时长 ≤ 1.5s，打字机 1s 后开始，不影响直接输入
3. 拓扑面板明确标注"非实时状态"，无伪造实时数据
4. 1366×768 至 2560×1440 无横向滚动；≤1020px 正常堆叠
5. `prefers-reduced-motion` 下所有循环动画停止，内容完整可见
6. 登录、错误、验证码刷新等现有功能行为与线上版本一致
