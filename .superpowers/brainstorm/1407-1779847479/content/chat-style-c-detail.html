设计要点

左侧栏

  • 对话历史列表，支持搜索
  • 新建对话按钮
  • 当前对话高亮
  • 显示最后活跃时间

聊天区

  • 单列消息流，头像 + 时间戳
  • markdown 渲染（表格、代码块、列表）
  • 建议操作按钮（快捷操作）
  • 引用块高亮显示建议

工具面板

  • 工具名称 + 执行状态 + 耗时
  • 参数和结果可折叠查看
  • 写操作带确认/拒绝按钮
  • 工具调用内联在消息流中

输入区

  • 自适应高度输入框
  • Shift+Enter 换行，Enter 发送
  • 圆形发送按钮
  • 底部提示文字
